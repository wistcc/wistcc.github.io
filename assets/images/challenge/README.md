# Imágenes del reto (/challenge)

- **portrait.jpg** — Retrato del hero. Reemplaza este archivo con tu foto de
  perfil de Instagram (mismo nombre) y la página se actualiza sola.
  Recomendado: cuadrada o 4:5, mín. 800px de ancho.
  Actualmente es un PLACEHOLDER (copia del avatar del sitio).

- **dia-XX.jpg** — (Opcional) Thumbnails de los episodios/Reels. Súbelos aquí
  y referéncialos en `_data/challenge.yml` → `days[].thumbnail`
  (ej. `/assets/images/challenge/dia-20.jpg`). No se descargan de Instagram.
